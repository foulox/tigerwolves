Admin powers on the All Runs screen — two directions

Same screen you and everyone else sees. The question is how your admin controls appear on it. Each card now carries a state: LIVE (public, joinable) · DRAFT (you're setting it up) · UNCLAIMED (catalog stub, nobody running it yet).

A

Always-on inline controls

As a leader you always see an edit pencil + state badge on every card, and an "add" tile at the end of each day. Nothing to switch on — you're always in a lightly-editable view. Runners never see any of it (role-gated).

B

"Manage" edit-mode toggle

The screen looks exactly like the public All Runs by default — clean, no clutter. A "Manage runs" switch flips it into edit mode, revealing pencils, delete, activate, and add tiles. Off by default so your normal browsing matches what runners see.
