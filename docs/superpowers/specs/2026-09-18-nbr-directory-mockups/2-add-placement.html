Where does "Add run" live?

No more per-day dashed tiles. One discoverable, admin-only "Add run" affordance. It's a rare action, so it should be easy to find but not dominate the screen. Three placements — the day list underneath is identical in all three.

A

Header button

Small "+ Add run" pill in the top bar next to the title. Clean, tucked with the other page-level controls, reads as "admin tools." Rare action → doesn't float over content.

B

Pinned bar under filters

A full-width "+ Add run" bar just above the day list. Most obvious of the three — impossible to miss — but takes a permanent stripe of vertical space up top.

C

Floating action button

Round "+" pinned bottom-right, standard mobile pattern. Always reachable while scrolling, never scrolls away — but floats over cards and can cover content.
